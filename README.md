# Meine Zeiterfassung

## Sofort testen
1. ZIP-Datei entpacken.
2. `index.html` im Browser öffnen.
3. Zeiten erfassen.

## Auf dem iPhone als App verwenden
Für eine echte Home-Screen-App muss der Ordner über eine kleine Website bereitgestellt werden, zum Beispiel kostenlos über GitHub Pages.

Danach:
1. Website in Safari öffnen.
2. Teilen-Symbol antippen.
3. „Zum Home-Bildschirm“ wählen.

## Speicherung
Die Daten liegen nur im jeweiligen Browser. Deshalb regelmäßig:
- Excel exportieren
- Datensicherung herunterladen

## Funktionen
- Start-/Endzeit in 15-Minuten-Schritten
- Sales, NBD, Marketing, Sonstiges
- Kategorien später änderbar
- Tätigkeit als Freitext
- Nachtragen, Bearbeiten, Löschen
- Lückenerkennung
- Wochenziel 40 Stunden
- Wochen- und Monatsauswertung
- Excel-Export
- JSON-Sicherung und Wiederherstellung
